## 功能与用法

以下说明对应当前源码的操作设计，未完成的验收见[优先级待办](#优先级待办)。

### 浏览、搜索与片单

手机和平板提供「首页 / 排行榜 / 搜索 / 我的」四个一级入口，切换时保留页面数据与滚动位置。

| 入口 | 用法 |
| --- | --- |
| 首页 | 官方推荐流，保留服务端顺序并去重；默认每批展示 10 条，下拉刷新，主动向下滚动接近底部时续页，失败保留已有内容并允许重试 |
| 排行榜 | 切换下划线榜单标签、刷新或续页；封面等比例铺满小圆角区域并裁切边缘，排名、标题、分类、集数与热度排列在右侧，热度采用大数字与小标签；列表使用细分隔线，超出边界的内容隐藏 |
| 搜索 | 输入停顿后显示官方联想，保存最近 20 次搜索；支持名称、自然季号、上线日期、热度、播放量等排序及连载状态筛选。部分接口失败时保留有效结果 |
| 详情 | 普通点剧直接进入播放，下载和兜底入口保留详情页；查看资料、简介、追剧与预约。选集每组 50 集，可定位当前集或输入集数跳转 |
| 我的 | 账号头部、快捷卡片及内嵌的追剧、历史、预约、上新预约片单；历史支持全部 / 已看完 / 未看完筛选，片单可搜索与编辑 |
| 卡片菜单 | 长按或点「更多」进入追剧状态与下载等操作；批量下载一次最多选择 50 部 |

红果提供真人剧、漫剧、AI 剧及分集。内容、清晰度与区域可用性取决于源站及网络；应用不解除源站 VIP 或其他授权限制。旧版来源记录仅作存档保留，当前只请求红果。

### 播放与续播

- 手机播放主界面按设计图采用深色背景：顶部为返回、当前集数、倍速与更多，中央为播放 / 暂停，右侧提供收藏、系列剧、下载及投屏，底部为剧名、弹幕入口、橙色进度条与「选集 · 状态 · 全 N 集」条；横向视频提供「全屏观看」，底部保留全屏按钮。点赞 / 评论数量及原著小说栏没有对应数据，不显示示例值。更多菜单保留清晰度、画中画与播放设置。
- 播放设置 → 弹幕 →「屏蔽关键词」支持包含式模糊匹配：每行一个或逗号分隔，忽略大小写、空格、零宽字符与全角字母差异；最多 100 个关键词、每个 50 个字符，自动去重。保存后立即过滤当前及后续弹幕，清空并保存可从已加载缓存恢复；按本地用户分别保存，随备份导入导出。
- 内部页签支持左右滑动切换：排行榜榜单、「我的」及独立片单的追剧 / 历史 / 预约 / 上新预约、播放器的简介 / 选集 / 系列剧及可用的下载选集、分页选集与播放选集区间。左滑进入后一项，右滑回到前一项，首尾停止；滑动片单正文切换当前片单，独立片单中的筛选区域按内层优先处理。底部首页 / 排行榜 / 搜索 / 我的保持点击切换。
- 预约与上新列表不会等待后台观看历史同步。切换页签取消该页面旧读取，切回 60 秒内的缓存可立即显示；缓存按官方账号、页签和待上线 / 已上线分别保存，并保留分页位置。下拉刷新主动更新，失败保留已有列表；预约变更或账号切换会失效相关缓存。首次读取显示加载状态，请求失败显示重试提示，不提前当作空列表。
- 点集数或底部选集条打开白色圆角面板，提供「简介 / 选集 / 系列剧」，下载从面板右侧图标进入；上方视频缩为预览并继续使用同一播放器。点面板外视频、下滑面板头部、关闭按钮或系统返回均先收起面板；选集后收起面板并播放所选集。平板使用相同内容的侧栏。选集每 30 集一段，支持横向定位与连续滚动；当前集橙色高亮，实际已看集数保留标记，底部可收藏 / 取消收藏。
- 点按画面显示或隐藏播放控件。画面任意位置双击播放或暂停，不再显示前后退按钮。横滑预览目标时间，松手跳转，也可拖动进度条。中央区域（播放交互区横向 30%–70%、屏幕高度 20%–80%）上滑下一集、下滑上一集；普通拖动达到屏幕高度 8% 切集，快滑最少移动屏幕高度 3% 且速度达到每秒 80% 屏高，未达条件时回弹。触发区域、距离、快滑和拖动上限均按屏幕高度计算，与视频比例无关。左侧纵滑调音量，右侧纵滑调亮度。长按 350 毫秒临时 3 倍速，松手恢复。锁定后点画面左侧的解锁按钮或按系统返回键解锁。
- 竖屏更多菜单和全屏设置均可选择画质、0.25–3 倍速、画面比例、静音及定时暂停，并可切换视频提供的音轨和字幕。画面比例按用户保存，定时暂停在退出播放器时取消。
- 片尾自动准备下一集：按当前倍速估算剩余时间，通常在最后约 30 秒实际播放时间且进入本集最后 40% 后开始解析与缓存；最后约 8 秒加急，不再要求片尾仍有整整 5 秒缓冲。预取预算为 8 MiB；HLS 最多预取 3 个媒体片段或约 12 秒，同时准备所需清单、密钥和初始化数据。当前集优先，后台 / 锁定 / 切用户 / 改清晰度 / 跳到其他集会取消或清理旧预加载。
- 自动连播优先接管下一集已准备的会话与缓存；在途结果最多短等 350 毫秒，未就绪或过期时回退正常取流。命中缓存时省去额外显式停播，进度保存及旧会话回收不阻塞下一集打开；短暂衔接先保留视频区域，超过 450 毫秒仍未完成则显示加载。仍使用同一个播放器打开下一集，编码 / 分辨率变化与设备解码器重建可能有间隔，实际接续效果待集中验收。
- 竖屏界面中的横向视频稍上移，弹幕与中央播放按钮同步上移；右下角不显示投屏入口。弹幕按身份及 8 秒内相同内容去重。
- 每 5 秒及退出播放时保存真实进度，各分集独立保存并优先续播，支持上下集往返、重启及备份恢复；选集用播放箭头标识当前集、勾号标识实际看过的集数，跳过的集数不视为已看。
- 多季数据使用官方相关作品接口。本季最后一集底部优先显示最近的已上线下一季跳转，不同时显示预约；只有当前已是最后一个已上线季、且存在后续未上线季时才显示预约。已发布但暂不可播放的更高季不会当作不存在而提前显示预约；其他集可打开「系列剧」面板查看关联季与同 IP 作品，已上线可播放、未上线可预约，查询失败会有限重试，空列表会退避补查，进入末集或打开系列剧时按需刷新，相关作品读取不再排队等待历史同步。系列剧先展示按官方季号升序排列的「本剧后续季」，下一组为「关联剧」，当前与更早的季保留在末尾「本剧其他季」；关联剧保留官方顺序，各组保留关系标签，按排行榜卡片样式纵向显示左侧封面、右侧剧名 / 分类 / 集数和操作，卡片之间用细线分隔，当前作品也使用相同布局并标注「正在播放」；只有官方季号参与下一季判断，同 IP 标签不会被当作下一季。切换作品前保存进度并暂停旧播放器，预约提交以官方操作接口成功响应确认，当前页直接更新并联动系列剧，不再阻塞扫描完整预约列表。
- Android 手机 / 平板的画中画入口位于倍速 / 清晰度菜单内，先关闭菜单再进入小窗；小窗隐藏自绘控件与弹幕。
- 红果在线播放默认开启弹幕，可用主界面下方「弹」字按钮关闭、查看状态或重试；本地播放不加载弹幕。
- 小米 Flip 外屏按实际窗口尺寸布局，保留系统安全区，视频保持原始比例；全屏按视频方向旋转整个播放界面。开合屏复用播放器，系统重建或外屏入口重开时尝试恢复当前用户最近 24 小时内的播放快照。主动退出播放或切换用户会清理快照。MIX Flip 2 的接续、最近任务、旋转、触摸及画中画仍待实机确认。

播放问题可从「我的 → 设置 → 播放调试日记」查看、复制或清空。日记自动保存到应用支持目录 `logs/playback.log`，每份最多 1 MiB，轮转保留 2 份旧日志；重启后恢复最近 500 条，连接手机可提取完整轮转文件及核心 `logs/app.log`。失败日志关联 trace、剧集 / 分集 / 视频身份、位置 / 缓冲、清晰度 / 线路、前后台、底层错误 / 堆栈和 Wi-Fi / 流量 / VPN / 联网状态，记录卡顿、首帧超时、解码回退与自动恢复过程，过滤凭据、完整地址和密钥。`[PlayTiming]` 关联点击、详情、取流、播放器准备等阶段，原生核心在应用支持目录的 `logs/app.log` 记录 `playback_timing`；日志不记录媒体 URL、内容密钥或账号凭据。接口取流时间不等于点击到首帧的时间。

### 官方账号与数据边界

官方账号绑定当前本地用户，支持中国大陆 `+86` 手机号验证码登录。若触发上行短信验证，按页面显示的本次号码和内容发送短信，返回后自动检查并继续登录；页面显示检查次数、等待状态和失败原因。超时或网络失败可在原页继续检查，已经验证通过可重试完成登录，明确过期后才需要重新获取验证码。取消会终止检查并忽略旧请求结果。图形验证等尚未接入的风控流程需要先在官方 App 完成。

| 数据 | 同步与保留规则 |
| --- | --- |
| 观看历史 | 登录后立即同步；新进度以 UTC 时间保存到本机队列，约 15 秒后尝试同步；每集播完、切集、暂停和退出播放立即调度，位置与上次保存相同时也会触发。运行且当前本地用户已解锁时每 90 秒继续重试；读取官方历史列表并合并较新进度，分批（每轮最多 50 条）上传，再回读历史列表确认视频身份、时间和进度；确认成功的记录独立落盘，未确认的保留队列。移除历史获取对额外进度查询接口的依赖 |
| 登录前的历史 | 登录后自动补传当前本地用户尚未加入账号队列的较新记录，复用已保存的视频身份，旧记录按需查询分集；个别失败不阻断其他记录，之后自动重试。删除或清空本机历史不会删除云端记录 |
| 追剧与收藏 | 合并本机追剧和账号收藏；登录后新增、取消追剧或标记状态时先提交账号收藏，回查确认后保存本机变更。想看 / 在看 / 已看状态保存在本机，旧追剧不会在登录时批量上传 |
| 预约 | 预约与上新预约独立读取官方列表，支持待上线 / 已上线及预约状态筛选；排期时间优先读取官方时间戳，按北京时间显示为 `YYYY-MM-DD HH:mm`，没有有效时间戳时保留官方说明文字；预约或取消以官方接口成功响应确认，超时不假定操作成功 |

打开「我的」、切换片单、恢复前台或从播放页返回时刷新相关数据；失败保留已有记录并显示原因。历史获取、上传与失败重试全自动处理，账号页仅显示同步状态、待上传条数、最近同步时间及失败原因，不提供单独操作按钮。待上传条数或同步时间变化只更新状态及缓存，避免反复刷新整个片单。登录后的资料同步失败单独提示，不把已完成的登录显示为失败。

### 下载、设置与设备互联

播放主界面右侧「下载」、底部面板下载图标及详情页可选择分集与画质；搜索页长按剧集进入多选，可批量下载。下载管理从「我的 → 下载」进入。下载管理提供暂停、继续、重试、删除及清理任务但保留视频；「更新本剧」补充新增或缺失分集。已有媒体库、合并和存储迁移实现，仍需集中验收。旧版已生成的本地视频保留在本地媒体列表，可继续播放或手动删除。

配置备份包含本地用户、追剧、历史和偏好，不包含下载视频、官方账号凭据或代理地址。恢复会替换本机用户、记录和设置，保留视频文件；已有应用标识、数据目录和备份格式保持兼容。

| 设置入口 | 行为 |
| --- | --- |
| 网络与资源 | 管理员可选择自动、直连或手动代理；支持 HTTP、HTTPS、SOCKS5 / SOCKS5h。自动模式读取系统静态代理和排除列表，恢复前台及每 30 秒更新；设备内播放服务绕过代理，不关闭 TLS 校验 |
| 请求与下载并发 | 目录请求并发 1–6、间隔 0–5000 毫秒，默认 3 / 250ms；下载并发 1–6，默认 2，保留前台优先、取消和退避 |

### 本地构建命令

先将 Flutter、Go 和 Android 工具加入 `PATH`。Android 通过 `ANDROID_HOME` 指定 SDK；如复用其他已安装 NDK，同时设置 `ANDROID_NDK_VERSION` 与 `ANDROID_NDK_HOME`，使主程序、插件和 Go 核心保持一致。本地脚本默认 `GOPROXY=https://goproxy.cn,direct`、`GOSUMDB=off`，可用同名环境变量覆盖。

以下命令使用本机或 CI 已配置的构建依赖。最近一次本机签名构建与设备验证见版本记录。

```sh
python3 scripts/build_android.py --abi arm64-v8a
python3 scripts/build_android.py --abi arm64-v8a --cn-mirrors
```

不传 `--abi` 时按脚本默认构建多个 Android 架构。Android 本机签名资料和证书核对要求见 `AGENTS.md`，口令只配置在被忽略的 `android/key.properties`，不纳入源码或压缩包。

构建产物位于 `dist/android/`，新文件以 `yeguo-` 开头。首次 Android 调试需先编译对应架构核心：

```sh
python3 scripts/build_native.py --abi arm64-v8a
flutter pub get --enforce-lockfile
flutter run
```

## 播放架构与性能

| 执行位置 | 职责与限制 |
| --- | --- |
| Flutter UI isolate | 手势、轻量播放状态、组件与字体测量；隐藏控件不消费常规进度刷新，可见进度合并到最多每秒 4 次；暂停、显隐、缓冲和手势即时响应 |
| 交互 worker，最多 2 个 | 取流、播放详情、弹幕请求以及 JSON 解码；大体量观看记录和配置快照编码在后台执行。小记录保留直接编码，避免线程通信开销 |
| 后台 worker，最多 2 个 | 目录、预加载、历史同步等核心请求；worker 按需建立后复用，队列有上限，无空闲轮询 |
| 独立控制 worker，最多 1 个 | 取消、会话释放等控制操作，不排在慢网络请求后；每个根 isolate 的池总上限为 5 个 |
| Go / mpv / Android | Go 网络请求与 context 取消继续在本机核心执行；mpv / MediaCodec 负责解码，保留硬件加速和原有缓冲策略；Flutter 绘制仍由 UI / raster 管线完成 |

切集意图立即使旧解析失效并发送取消，不必等历史存储完成；未启动的同范围旧任务直接从队列移除，已启动读请求通过序号调用 Go context 取消，迟到结果仍校验归属与代次。弹幕、预加载的旧页面不能取消新页面任务。不可取消的持久化写入保留执行，避免丢失历史；后台任务取消不等于强杀进程或强停 C / Go 调用。

弹幕使用一个 Ticker 驱动 Flow 的绘制变换，保留文本缓存与碰撞排程；每条文字不再建立 AnimationController，常规位置变化不再通知弹幕组件和设置面板重建。暂停、缓冲、隐藏或没有活动弹幕时停止逐帧时钟，下一条弹幕使用单次定时唤醒。字体测量与绘制遵守 Flutter 主 isolate 限制，不宣称已移到后台线程。全屏系统时间只在可见时于分钟边界更新；恢复快照的常规保存降到约 5 秒，主动暂停、切换、退出仍即时检查点；暂停或后台不可见时停止播放维护及周期保存定时器。

方案依据：[Flutter 长期 isolate 与限制](https://docs.flutter.dev/perf/isolates)、[Flow 绘制阶段变换](https://api.flutter.dev/flutter/widgets/Flow-class.html)、[Flutter 性能建议](https://docs.flutter.dev/perf/best-practices)、[media_kit Android 控制器源码](https://github.com/media-kit/media-kit/blob/main/media_kit_video/lib/src/video_controller/android_video_controller/real.dart)、[Go context 取消约定](https://pkg.go.dev/context)。本轮未升级播放器依赖，也未降低画质或帧率。

目前证据是执行次数和正确性：连续 20 次正常进度更新触发 0 次弹幕通知，暂停立即通知；阻塞模拟任务不影响主 isolate 心跳，取消控制可绕过繁忙工作线程，连续任务复用同一 worker，旧解析、旧弹幕回包不会接管新页面。未进行等亮度、同视频、同网络的长时间功耗对照，不能给出电量或温度改善百分比。
